How this demo works

Every workspace above is live and connected: member requests, gate check-ins, orders, plans and repairs travel between open tabs of this browser and survive refresh. Statuses only change by human action, never timers, and no event applies twice. True cross-device sync, staff logins and payments are the production backend (Supabase — schema already written), which this demo intentionally leaves out.
