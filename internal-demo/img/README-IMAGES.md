# Level Up OS — image library

Every file here is a **brand-styled SVG placeholder** (black/warm-beige, sharp
chevron motif) sized 640×360. They keep the demo visually consistent until
real Level Up photography arrives.

## Replacing with real photos

Swap any `.svg` for a real photo by dropping a `.webp` with the **same
basename** next to it and updating the reference (`img/class-trx.svg` →
`img/class-trx.webp`). Keep one consistent crop, contrast treatment, and warm
neutral color grade — do not mix five photography styles.

Use **official Level Up photos** for all brand-defining screens (login hero,
branch cards, trainer profiles — real staff, never stock people). Use stock
(Pexels/Unsplash, license-checked) only as temporary filler for menu/product
cards. Do not hotlink Instagram URLs — download approved originals.

Export targets when real photos come in:

| Use | Ratio | Export |
|---|---|---|
| Login hero | 9:16 | 1440×2560 |
| Class card | 16:9 | 1280×720 |
| Branch card | 3:2 | 1200×800 |
| Trainer portrait | 4:5 | 1000×1250 |
| Menu product | 1:1 | 1000×1000 |
| Promo banner | 2:1 | 1600×800 |
